Project Overview

ROAR is a tactical first-person multiplayer shooter featuring cooperative squad loops and competitive engagements. The development focused on providing responsive shooter mechanics supported by authoritative online session infrastructure and robust network replication.

My Technical Contributions

  • Epic Online Services (EOS) Integration: Implemented end-to-end online flows including EOS authentication, lobby creation, party management, platform friend invites, and lobby team assignment.
  • Companion AI System: Architected tactical companion bots using Behaviour Trees, Blackboards, and EQS queries. Companions respond dynamically to player commands, navigate complex layouts, take cover, and engage targets autonomously.
  • Gameplay Replication & Synchronization: Developed authoritative health/damage pipelines, weapon inventory switching, projectile spawning, and pawn state replication in a hybrid C++ and Blueprint environment.
  • REST API & Framework Integration: Integrated RESTful web endpoints using the VaRest plugin for backend user data and worked extensively with the SKGSF shooter framework and GASP locomotion.

Challenges & Engineering Decisions

Online Session Consistency: Ensuring seamless transition between squad party formation and match server travel required careful handling of EOS session states and player connection validation. Handled asynchronous EOS callbacks with timeout safeguards to avoid players hanging in connection limbo.

AI Replication Overhead: Companion bot pathfinding and high-frequency target evaluation can consume significant CPU cycles in multiplayer sessions. Optimized query frequencies, implemented distance-based tick management, and pooled sensory perception updates to ensure stable server frame rates.
