Project Overview

Soul Eater is an ability-driven roguelike mobile shooter where players battle escalating waves of demonic monsters. Built on Unreal Engine 5 for Android devices, the project demanded rigorous performance engineering to handle dense particle effects and high enemy counts on mobile chipsets without sacrificing responsiveness.

My Technical Contributions

  • Interface-Based Communication: Eliminated hard Blueprint casting references across player characters, enemy pawns, and UI elements. Replaced with Blueprint Interfaces (BPI), eliminating circular memory loads and reducing initial mobile package load times.
  • Enemy Horde Object Pooling: Built an actor pooling system to recycle enemy actors, hit sparks, and damage number widgets instead of continuously spawning and destroying objects during 200+ monster waves.
  • Mobile Asset & Texture Optimization: Implemented ASTC texture compression, clamped max texture resolutions, created compact material instances, and audited level geometry to maintain a tight memory footprint.
  • Progression & Augment Logic: Architected the randomized 3-card augment selection system (*Soul Siphon*, *Overclock*, *Chain Reaction*) with weighted rarity tiers, stat modifiers, and mobile touch input handling.

Challenges & Engineering Decisions

Garbage Collection Hitches on Android: Frequent spawning and destruction of hundreds of projectiles and defeated demons triggered noticeable Android garbage collection stalls. Implemented pre-allocated object pools, ensuring smooth frame pacing during peak horde moments.

Mobile Touch Ergonomics: Rapid twin-stick movement requires tight feedback without finger fatigue. Implemented a floating virtual joystick with dynamic origin positioning alongside responsive radial cooldown badges.
