Project Overview

Happy Now 2 is an energetic mobile arcade title engineered to deliver instant gameplay gratification with clean touch responsiveness and engaging replay loops. Built entirely from scratch in Unreal Engine 5 for Android, the title balances vivid stylized visuals with a lightweight memory and rendering footprint suitable for diverse Android mobile hardware.

My Technical Contributions

  • Core Gameplay & Input Responsiveness: Engineered custom touch swipe and tap input recognition with zero-latency gesture buffers, allowing players to execute precise maneuvers through high-speed obstacles.
  • Progression & Reward Loops: Developed a save system tracking player high scores, currency accumulation, unlockable cosmetic rewards, and dynamic difficulty scaling based on session performance.
  • Mobile UI/UX Architecture: Implemented responsive UMG interface layouts adapting cleanly across varied mobile aspect ratios from 16:9 to 21:9 with DPI scaling curves.
  • Android Performance Tuning: Profiling and optimization using Unreal Insights and Android GPU benchmarks, maintaining stable 60 FPS across mid-range and high-end Android devices.
