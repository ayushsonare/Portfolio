VR Tour

An immersive virtual reality architectural walkthrough featuring real-time material swapping, dynamic wall color customization, physics-based object interactions, and stable 90 FPS VR frame pacing.

Project Type VR Interactive Walkthrough
Platform & Engine VR (OpenXR) · Unreal Engine 5
My Role VR & Gameplay Systems
Project Context Personal Project
Gameplay walkthrough demonstrating real-time wall color changing, dynamic material selection, spatial object inspection, and comfortable teleportation locomotion.

Project Overview

VR Tour is an interactive architectural visualization experience engineered to give clients and users complete physical presence inside an interior space before construction or remodeling. Built with OpenXR on Unreal Engine 5, the tour enables users to naturally explore rooms, manipulate props, and test different interior color palettes and surface materials in real time.

The project focuses on creating responsive spatial user interfaces (diegetic 3D palettes) and seamless 6DOF controller hand interactions while maintaining strict 90 FPS stereo rendering to prevent motion sickness.

My Technical Contributions

  • Dynamic Material & Color Customizer: Authored dynamic material instances with scalar and vector parameter hooks, allowing users to point-and-click or laser-select walls, floors, and furnishings to switch paint colors and texture finishes instantly without hitching.
  • Diegetic 3D Spatial UI: Designed a floating contextual palette attached to the user's non-dominant controller hand, providing clean color swatches and finish toggles without breaking spatial immersion.
  • 6DOF Object Interaction & Physics Grabbing: Implemented physics handle components for realistic pick-and-throw object handling, dual-hand rotation, and snap-to-socket shelf placement.
  • Comfort-Focused Locomotion: Programmed parabolic arc teleportation with customizable rotation snap turns and optional peripheral vignetting to ensure comfortable navigation for all VR comfort levels.
  • VR Performance & Stereo Optimization: Calibrated Forward Shading, Instanced Stereo Rendering, and audited Nanite/Lumen settings to guarantee locked 90 FPS performance in stereo headsets.

Challenges & Engineering Decisions

Real-time Material Switching Without Hitches: Compiling new shaders or creating heavy material assets on the fly in VR causes frame drops that instantly cause nausea. Pre-instantiated dynamic material instances at level start and updated vector parameters via material parameter collections, ensuring instant, zero-cost color transitions.

Intuitive Spatial Ergonomics: Standard flat 2D menus feel cumbersome and detached in 6DOF VR. Developed physical color-picker spheres and laser interaction widgets anchored in 3D world space that respond with subtle haptic controller impulses on hover and click.
