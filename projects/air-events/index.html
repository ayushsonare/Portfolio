Project Overview

AIR EVENTS was developed to bridge physical conferences and virtual gatherings. Built on Unreal Engine 5, the platform combines multiplayer networking, spatial interaction, custom avatar identity, and dynamic presentation venues into a unified interactive space.

My Technical Contributions

  • Multiplayer Presence & Synchronization: Engineered real-time character movement replication, spatial orientation, and smooth interpolation across multi-user sessions using EOS and Unreal Engine networking.
  • Avatar Customization Pipeline: Built a modular character customization system allowing participants to configure clothing, body presets, hairstyles, and digital identity tags with real-time replication to other clients.
  • Interactive Presentation Workflows: Developed synchronized media display boards capable of streaming presentation slides, keynote videos, and event schedules with synchronized playback across attendees.
  • Cloud & Web Service Integration: Connected Unreal Engine runtime systems with web backend APIs and AWS S3 endpoints for user authentication, asset fetching, and profile verification.

Challenges & Engineering Decisions

Dense Multi-User Optimization: With dozens of customized participants congregating in auditoriums, skeletal mesh draw calls and animation ticks can bottleneck performance. Resolved this by implementing distance-based Animation Budget Allocator settings, LOD stepping, and dynamic mesh pooling for off-screen avatars.

Synchronized Media Playback: Keeping presentation boards in sync across attendees joining at different times required a dedicated server-authoritative timestamp system. Clients calculate offset on connect, ensuring smooth slide and video alignment without lag.
